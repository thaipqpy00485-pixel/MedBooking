# MEDBOOKING

## Hệ thống đặt lịch khám bệnh

MEDBOOKING là hệ thống hỗ trợ người dùng tìm kiếm bác sĩ, xem lịch làm việc và đặt lịch khám bệnh trực tuyến.

## Chức năng chính

- Đăng ký tài khoản
- Đăng nhập / đăng xuất
- Quản lý thông tin bệnh nhân
- Xem danh sách bác sĩ
- Xem chuyên khoa
- Xem lịch làm việc của bác sĩ
- Đặt lịch khám
- Hủy lịch khám
- Xem lịch sử đặt khám
- Quản lý bác sĩ
- Quản lý chuyên khoa
- Quản lý lịch hẹn

## Tài liệu dự án

- SRS - Đặc tả yêu cầu phần mềm
- Use Case Diagram
- Class Diagram
- Object Diagram
- Sequence Diagram
- Activity Diagram
- Kiến trúc hệ thống
- Test Case

## Quản lý dự án

Dự án sử dụng:
- GitHub để quản lý mã nguồn và tài liệu
- Trello để quản lý công việc theo Sprint
